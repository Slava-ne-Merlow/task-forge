Система управления задачами для команды

Описание проекта (от бизнеса)
Приложение для распределения задач внутри команды с отслеживанием времени и прогресса.
Бизнесовые требования (верхнеуровневые)

Пользователь может создавать проекты с участниками.

Пользователь может создавать задачи с исполнителем и дедлайном.

Пользователь может оценивать трудоёмкость задач в часах.

Пользователь может фиксировать затраченное время на задачу.

Пользователь ожидает доску задач со статусами.

Пользователь может назначать приоритеты задачам.

Пользователь может комментировать задачи и добавлять вложения.

Пользователь ожидает отчёт по загрузке участников команды.

Пользователь может создавать шаблоны повторяющихся задач.

Требуется авторизация и разделение данных между командами.
